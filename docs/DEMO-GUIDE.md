# Demo walkthrough (5–10 минути)

Подготовка (веднъж): `npm run setup:demo`, `npm run owner:create`, после `npm run dev:all`. Отвори http://localhost:3015.

Всички бизнеси са синтетични („ДЕМО …“, маскирани недиалируеми номера `+359 XX XXX X061 (ДЕМО)`). Нищо не е реално намерен клиент.

1. **Вход и „Днес“** — влез. Виждаш „25 / 25“ нови (синтетични), обработени днес, просрочени/днешни последващи, „Останали от предишни дни“ (seed история за 3 дни), бележка за преразпределението на квотите (няма избрани „други“ градове → само Варна/Плевен).
2. **Score и доказателства** — кликни бизнес в таблицата. Вдясно е панелът с всичките 18 групи полета: score 0–100 с разбивка „защо“, статус на сайта със синтетично доказателство, „Предложение по шаблон“, източник/разрешения, допустимост с причини.
3. **„Да се обадя отново“** — „Започни обажданията“ → първият контакт → „Симулирай обаждане“ (без tel:) → „Да се обадя отново“ → „Да, говорихме“ → дата/час → „Запази и следващ“. В „Последващи → Предстоящи“ се появява задачата.
4. **Оферта** — вторият контакт → „Изпрати оферта“ → „Запази и следващ“. В „Оферти“ има **чернова** (нищо не е изпратено). Натисни „Маркирай като изпратена (ръчно)“ — това означава, че ти си я изпратил извън приложението.
5. **Приета → Спечелен** — „Приета“ на офертата. Отвори контакта (линк от картата) → „Спечелен клиент“ (сумите са попълнени от пакета) → „Запази резултата“. В „Клиенти“ има договорена сума и **получено 0,00 €**. Плащане се записва само ръчно.
6. **DNC** — третият контакт в „Обаждания“ → „Не се свързвай повече“ → „Да, говорихме“ → запис. В детайлите: „Обажданията са блокирани“, „Позвъни“ и „Нова оферта“ са disabled с причина. Backend също отказва (409).
7. **Следващ демо ден** — „Днес“ → демо панел → „Симулирай следващ ден“ → потвърди. Горе се появява „симулиран ден +1“ и нов списък от 25 **други** бизнеса. Вчерашните непозвънени са в „Останали от предишни дни“.
8. **Повторно генериране** — „Създай днешния списък (idempotent)“ → „Списъкът вече съществува (25/25) — нищо ново не е генерирано.“
9. **Известия и статистика** — „Покажи известието“: in-app preview на push текста (без имена/телефони) и на резервния имейл (fallback по липса на отваряне), с ясно „НЕ е изпратено“. „Статистика“: опити, разговори, интерес, оферти, спечелени, договорено и отделно получено, с дефиниции на знаменателите и „малка извадка“.

Допълнително: „Прегледай утре (без резервиране)“, „Нови клиенти / база“ (табове, филтри, ръчно добавяне, CSV импорт с preview, export), Pipeline с падащо меню, Настройки → Health (worker пулс, резерв, следващо изпълнение, jobs/outbox).

CLI алтернативи: `npm run jobs:daily:dry-run`, `npm run demo:next-day`, `npm run backup`.
